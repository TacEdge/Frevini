# Frevini Studio — Brand Assets

Organised copies of the assets required to produce Frevini Studio collateral.
Nothing in this folder is a site file; the live website and its media library remain the master source.

## Installing the fonts

Install `Marcellus-Regular.ttf` and the five static DM Sans files.
Word and PowerPoint users should install the static files, not the variable font.
Both families are licensed under the SIL Open Font License 1.1 and may be embedded in PDFs and shared with agencies.

## Using the logo

Green on white or warm white. White on Frevini Green or on the dark region of a photograph.
Black only for single-colour reproduction (stamps, engraving, fax-grade print).
Minimum width 28 mm in print, 120 px on screen. Clear space = the height of the frame tail on every side.
Never redraw, re-set or recolour the mark. Never add a drop shadow, outline or gradient.
